# Marasi Drive - HoloXDubai

Проект на Vue 3 + Vite для отображения информации о жилом комплексе Marasi Drive.

## Технологии

- Vue 3
- Vite
- Vue Router
- Шрифт Usual

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

## Сборка

```bash
npm run build
```

## Предпросмотр production сборки

```bash
npm run preview
```
